# Barbearia Leme

Site de demonstração para barbearia em Lauro de Freitas. Agendamento no navegador, confirmação pelo WhatsApp.

Os dados da casa (nome, preços, barbeiros, horários, WhatsApp) ficam em `src/shop-config.ts`.

## Local

```bash
npm install
npm run dev
```

## Vercel

Importe este repositório. O build command é `npm run build`.
